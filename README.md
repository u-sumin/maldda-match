# 말따 MATCH — 토목 말따먹기 짝맞추기 게임

모바일과 PC 브라우저에서 실행되는 정적 웹 게임입니다. 추가 설치 또는 서버가 필요하지 않습니다.

## 출제 모드

- **출제 범위:** 전체 / 못 외운 것 / 암기 완료
- **문제 수:** 20~100개 랜덤 선택 또는 **전범위 모두** (전체 선택 시 323개)
- 미암기 범위에서 전범위 모두를 선택하면 미암기 문항을 모두 출제합니다.
- 제한 시간: 0(무제한) ~ 180분
- 한 세트당 최대 3쌍씩 문제와 답을 연결합니다.

## GitHub Pages 배포

1. GitHub에서 **Public** 새 저장소 생성 (`maldda-match` 등).
2. 이 ZIP 파일을 **압축 해제**하고, 내부의 `index.html`, `.nojekyll`, `README.md`를 저장소 최상위에 업로드합니다. (ZIP 파일 자체를 올리면 사이트가 동작하지 않습니다.)
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. **Branch: main**, **Folder: /(root)**를 선택한 뒤 **Save**를 누릅니다.
5. Pages 화면에 표시된 **Visit site**를 통해 접속합니다.

저장소 이름이 `maldda-match`라면 예시 URL은 `https://깃허브아이디.github.io/maldda-match/`입니다.

## 암기 기록 주의

암기 완료는 브라우저의 **localStorage**에 저장됩니다. GitHub에 업로드되지 않으며 다른 기기와 자동 동기화되지 않습니다.
기존 HTML 파일에서 체크한 기록을 옮기려면 **암기 기록 백업하기**로 JSON을 저장한 후 새 사이트에서 **암기 기록 가져오기**를 사용하세요.

## 공개 게시 주의

Public GitHub Pages에 올린 문제와 정답은 웹상에 공개됩니다. 자료의 저작권과 공개 허용 여부를 확인한 후 배포하세요.
