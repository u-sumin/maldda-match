# 말따 MATCH — 단원 복수 선택 / 오타 수정 업데이트

## GitHub Pages에 올리기

`index.html`을 기존 GitHub 저장소 `u-sumin/maldda-match`의 루트 위치에 있는 `index.html`과 교체한 뒤 Commit changes를 누르세요.
기존 `cloudflare-worker.js`, `schema.sql`은 자동 동기화 서버 연결용 예시이며, 이미 서버를 배포했다면 이 업데이트 때문에 서버를 다시 배포할 필요는 없습니다.

## 바뀐 기능
- 게임 출제 단원: 체크박스로 14개 단원을 복수 선택. 초기 상태는 전체 선택.
- 문제 보관함 단원: 게임과 별도의 체크박스로 복수 선택. 초기 상태는 전체 선택.
- 문제 보관함: 한 페이지에 50문제. 기본 필터는 미암기.
- 한 세트당 5쌍 고정, 제한시간 설정 삭제(화면에는 경과 시간만 표시).
- 62번: 중복된 깨진 텍스트를 제거하고 원본 피어공법 표 그림만 문제 화면에 표시.
- 75, 110: 답안 그림 제거, 수식 텍스트 유지.
- 174, 177, 179, 265: 문제 그림 제거, 텍스트 문제 유지.
- 오타 및 지정 답안: 14, 15, 48, 71, 79, 84, 101, 104, 146, 159, 210, 247, 248번 수정.
- 암기 완료 기록 키, 문제 id 유지. 기존 자동 동기화 방식도 유지.

## 참고
그림이 제거된 75번과 110번은 텍스트로 표시되는 수식을 확인하세요. 원본 PDF와 다른 표기여부는 사용자 요청에 따라 오타를 수정한 부분이 우선합니다.
