# 말따 MATCH (단원별 5쌍 짝맞추기)

첨부 PDF를 기준으로 14개 단원을 분류한 323개 짝맞추기 카드를 제공합니다.

- 게임에서 단원별 또는 전체 출제
- 전체 / 미암기 / 암기완료 범위 설정
- 출제 문항 1~100개 또는 선택 범위 전체
- 한 세트 2~5쌍 카드 선택
- 게임 전체 시간제한 설정
- 원본 PDF의 그림과 표 확대 보기
- 로비에서 암기 체크, 백업/복구

## GitHub Pages 업데이트

1. GitHub에서 기존 `u-sumin/maldda-match` 저장소에 들어갑니다.
2. 최상위 `index.html` 파일을 새 파일로 교체합니다. (파일명과 위치는 그대로)
3. Settings > Pages에서 Source: Deploy from a branch, Branch: main, Folder: /(root)인지 확인합니다.
4. 배포 후 https://u-sumin.github.io/maldda-match/ 을 새로고침합니다.

> 암기 상태는 브라우저 localStorage에 저장됩니다. 동일한 도메인 주소의 같은 브라우저에서는 기존 체크가 유지됩니다. 사이트를 변경하거나 기기를 바꾸기 전에는 '암기 기록 백업하기'를 사용하세요.

> GitHub Pages는 기본적으로 Public 저장소에 내용을 공개합니다. 원본 자료의 공개 가능 여부를 확인하세요.
