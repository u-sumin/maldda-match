☁ 자동 동기화연결 확인 중

암기 체크와 북마크가 연결된 기기에 함께 저장됩니다.

아직 연결하지 않아도 이 기기에 암기 기록은 저장됩니다. 동기화를 사용하려면 무료 Cloudflare 백업 서버를 먼저 만들어야 합니다.

다른 기기에서 이미 동기화를 시작했다면

기존 기기에서 기기 연결 링크 복사를 눌러서 링크를 이 기기에서 열면 자동으로 연결돼요. 링크를 보낼 수 없다면 아래에 동기화 키를 붙여넣어도 됩니다.

체크는 자동 저장돼요. 필요하면 아래 버튼으로 즉시 보내거나 받아올 수 있어요.
기기 연결 링크 / 상세 설정
연결 키와 링크를 아는 사람은 암기 기록에 접근할 수 있어요. 공개 게시물에 공유하지 마세요.

연결 해제는 이 기기의 자동 동기화만 중단합니다. 이 기기의 암기 체크와 서버 기록은 지우지 않습니다.

기기에서 변경한 체크는 인터넷이 잠시 끊겨도 이 기기에 남아 있어요. 연결이 돌아오면 재전송합니다. 같은 문제를 두 기기에서 동시에 다르게 체크하면 나중에 서버로 전송된 상태가 적용됩니다. 중요한 기록은 JSON 백업도 가끔 보관하세요.
